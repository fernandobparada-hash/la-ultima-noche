# LA ÚLTIMA NOCHE — Capítulo I · Alpha 4.4

Proyecto Godot 4.2+ (GL Compatibility). Abrir `project.godot` con Importar y ejecutar con F5.

## Controles (PC)
WASD/flechas mover · Shift correr · C agacharse · E examinar · F linterna · I inventario · M mapa · J/K ataques · Q cambiar arma · Espacio esquivar · R reaparecer tras morir.
En móvil hay controles táctiles en pantalla.

## Carpetas
- `scripts/` código · `scenes/` escenas · `assets/` arte y audio
- `docs/` historial de cambios (CAMBIOS_*.txt) y README anterior
- `referencia/` láminas de referencia (ignorada por Godot)
